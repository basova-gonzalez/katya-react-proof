# Прототип для Миши — рабочий документ

## Цель и принятая композиция

Короткий англоязычный отклик на part-time product designer: показать сильный визуал, дизайн прямо в React и качественную мобильную версию. Ориентир — композиция и контраст исходного https://unknw.com, тёмное поле, редакционная типографика, компактное меню.

Пользователь отказалась от блока с рекомендациями про LLM. Не возвращать фильтры, вымышленные проекты, бриф и блок site ↔ LLM.

## Новый вариант

- Hero: `Original ninja since 2013, no Figma required`, краткое личное обращение Мише и работа прямо в React. По просьбе пользователя слово проходит цикл ninja → maker → coder → ninja, через перебор кодерских символов с асинхронной фиксацией букв; тонкая линия сканирует шапку. Налезание символов и длинных слов на соседний текст — явно запрошенная фича. Место в строке фиксировано по ширине ninja, вне экрана анимация приостановлена, reduced motion оставляет исходный текст.
- Справа большая карточка GONZIK → KABAGO, на высоту двух маленьких. Сохранены цельные сгенерированные позы и удар по GONZIK; камера прикрывается терминалом. Не разрезать сцену удара на карточки.
- Слева две вспомогательные обложки: архив GONZIK / 2013 и переход от камеры к красному терминалу. Это история, не вымышленные кейсы.
- Тёмное поле, чёрный, сигнальный красный; никакого бежа. Большая правая обложка на ровном ярко-зелёном фоне #c8ef31, включая сцену слогана. Фото ткани и размытие убраны по просьбе пользователя. Белый остался у архивной карточки.
- На мобильном: большая карточка первой, затем две вспомогательные. По последней правке меню закреплено снизу с учётом safe area; в конце страницы оставлен запас, чтобы футер можно было прочитать над меню. В меню только крупный силуэт исходного ниндзя, без слов GONZIK и FOTODESIGN и без белых полей исходного квадратного файла.
- Контакты Telegram и GitHub только в меню, без дублирования в футере. GitHub ведёт на профиль, не обозначать его репозиторием этого проекта. Большая декоративная стрелка удалена. Нижняя строка по образцу UNKNW: © Ekaterina Básova González · 2026 · post-figma designer; красная фраза `Your site moved on. Your llms.txt stayed in August.`, рабочий `/llms.txt`, `Last checked: Sep 16. Last context: Aug 11.`, `codex build 0.1.0`. Текст задан пользователем, это не возврат рекомендаций про LLM. Кегль увеличен на десктопе и мобильном. Подзаголовок hero: `hey Misha. a little visual proof, / design straight in React, no layers in between.`
- Motion for React используется для появления карточек и движения терминала; основная сцена использует CSS-тайминг. Учитывается reduced motion, CSS-анимации обложки приостанавливаются за пределами области просмотра галереи.
