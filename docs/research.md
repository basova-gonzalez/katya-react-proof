# Research notes

Checked 16 September 2026 against UNKNW’s public home page and `llms.txt`.

- The home page presents work and events as a chronological editorial feed with short, assertive project language.
- Public copy treats a brief as the opening to a human conversation and makes a machine-readable summary available through `llms.txt`.
- References applied here: high contrast, warm light type on graphite, red-orange accent, oversized type, mono labels, dense grid rhythm, restrained movement.

The later visual pass against the live home page and its public CSS found the main differences that the first local design missed: a high-contrast serif hero (Grafier in the original), large sans subline, narrow red scanlines, a floating white navigation dock at the bottom, and an editorial media grid that enters the first viewport. Kate's review established three specific corrections: align cover tops, strip the descriptions under covers, and make the background lines noticeably move. The final headline is a short personal line in English, set in OFL DM Serif Display. This prototype uses fictional covers instead of UNKNW's assets or commercial font.

A short choice-based intake can make an unclear request actionable without a long form. Showing the same state as plain language and JSON lets a person verify what an agent receives. The compact gallery keeps structured catalogue data available for filtering and agent context while keeping the visible case presentation short.

Sources are references, not assets or endorsements. No logo, typeface, case-study imagery, client material, or claim of collaboration has been copied. The `robots.txt` and `sitemap.xml` source URLs could not be retrieved by the research tool on the check date, so no assertion about their contents is made.
