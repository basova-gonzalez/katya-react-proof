# Product and UX decisions

This independent case is a compact proof for Misha: visual craft in React, a clearer path from request to brief, and structured LLM context. The personal introduction and interactive demo are in English. It has no external data flow.

- Three direct links point to the visual system, improved flow, and LLM handoff. The floating dock requires no menu click.
- The composer asks for task type, product stage, clarity need, and timeframe, then renders a readable summary and JSON.
- The fictional catalogue filters locally. Covers align at the same height and show only a name and one category. Freshness metadata remains in the data/context layer and is not displayed under covers.
- Agent context combines the readable brief, JSON, two selected synthetic examples, and routing rules. It is copyable with a visible manual-copy fallback.

The page has only a personal hero, one gallery, the working brief/LLM demo, and a small footer. It uses a graphite canvas, warm off-white type, red-orange accent, mono utility labels, and original CSS graphics. DM Serif Display supports the English editorial headline; Geist Sans and Geist Mono support body and utility text. All three are bundled locally under SIL OFL 1.1. Red background lines move continuously and can be paused. Entrance, hover and section motion respects reduced-motion preferences.

Preview metadata, `robots.txt`, and the sitemap block indexing because the prototype has no public canonical URL. A public launch requires a separate decision to supply its approved URL and reverse that policy.
